# 🌾 Global Food Security Dashboard

An interactive data analytics dashboard that explores global food security through food prices, fertilizer costs, agricultural production, and food insecurity indicators.

## Project Overview

The Global Food Security Dashboard provides visual analysis of historical food security data. It allows users to explore trends, compare indicators, and examine statistical relationships using interactive visualizations.

## Features

- **Dashboard Overview** – Displays key food security indicators.
- **Food Price Analysis** – Explores food price trends and major commodity prices.
- **Fertilizer Cost Analysis** – Examines fertilizer price movements and their relationship with food prices.
- **Agricultural Production** – Analyzes food production, cereal yield, and arable land.
- **Food Insecurity Analysis** – Explores undernourishment and food supply stress indicators.
- **Relationship Analysis** – Examines correlations between selected indicators.
- **Key Findings** – Presents the major findings and interpretations.

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly

## Installation and Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/global-food-security-dashboard.git
   ```

2. Navigate to the project folder:

   ```bash
   cd global-food-security-dashboard
   ```

3. Create a virtual environment:

   ```bash
   python -m venv .venv
   ```

4. Activate the virtual environment:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

5. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

6. Run the dashboard:

   ```bash
   streamlit run main.py
   ```

## Notes

The dashboard presents statistical patterns and associations within the available dataset. Correlation does not establish causation.
